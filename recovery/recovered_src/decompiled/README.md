# 反编译/重建核心

本目录包含两种不同层级的证据：

- `c_pseudocode/`：来自重定基静态镜像的 Hex-Rays 输出。这些是
  编译器级重建，不是原始 Python 源码。
- `*.py`：根据 Hex-Rays 输出、运行时模块字典和观察到的状态转换编写的
  Python 级重建。

Python 文件中使用的置信度标签：

- `exact`：名称/签名/常量已由模块元数据或字符串确认。
- `high`：控制流或字段映射已由多次静态/运行时观察确认。
- `inferred`：行为根据名称、常量和观察到的输出重建；并非逐字节原始代码。

不要运行目标程序来验证这些文件。目标程序有一条反调试
路径，会记录 `反调试: 禁止调试 X` 并调用 `shutdown.exe`。
